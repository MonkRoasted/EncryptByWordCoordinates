# EncryptByWordCoordinates
**Location-Based Encryption** is an innovative encryption system that replaces traditional mathematical cryptography with a content-aware approach. Instead of abstract random keys, this system uses the location coordinates of words extracted from PDF documents as the basis for encryption and decryption.
